## 耗时的具体口径

**页面更新时间**从浏览器捕获真实click事件开始，到MutationObserver首次观察到预定义完成条件成立。例如调查后扣点且地点按钮消失、发言写入记录且输入框清空、结算后出现结局。它包含本机API请求与React状态更新，不等同网络往返时间、渲染帧性能或用户理解速度。

**自动化全流程耗时**从首页教程入口点击前到经手记回看结局完成，连续执行、不人工停顿。它包含脚本定位、自动滚动、断言核对和驱动/动画帧等待，未模拟阅读、推理、犹豫或真人打字，不能写成“用户平均XX秒完成推理”。

**计时修订公开保留**：R01—R05只采集完成条件后双requestAnimationFrame的时间；该读数常包含明显额外帧等待。R06起增加“DOM完成”和“动画帧等待”两个原始字段，保持步骤、原帧时间与24轮分母不变。190次页面更新时间来自R06—R24共19轮、每轮10次关键操作；前5轮没有该字段，未插值、减常数或补造。336条全部操作记录（含导航）及240条关键操作的原双帧时间均保留，便于检查。

P95使用最近秩法：升序排列后取第 `ceil(0.95×样本数)` 项。缓存自然复用，未限制CPU或网络，结果不能外推公网、并发负载或其他设备。
