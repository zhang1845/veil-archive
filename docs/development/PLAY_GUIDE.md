# 首页新手教程入口

日期：2026-10-29。按用户要求，教程独立展示，不嵌入剧本库或对局。

## 当前入口与路径

首页 http://127.0.0.1:3001 的“进入剧本档案”旁放置“新手教程”按钮，通往 http://127.0.0.1:3001/guide 。

独立页面包含推荐体验、五步操作顺序和常见问题，并提供“去选剧本，开始体验”及返回首页入口。内容解释选角、私本、调查点、物证与口供、公开发言、结算和中断恢复，不含案件谜底。

剧本库已移除展开教程；对局内已移除教程入口、教程正文和“现在该做什么”阶段指导卡。原有本地试玩状态、游戏操作、存档及权限保持。

- `frontend/src/components/play/PlayGuide.tsx`：仅供教程页使用的五步说明与原生可展开常见问题。
- 剧本库和PlayRoom不再导入教程组件。
