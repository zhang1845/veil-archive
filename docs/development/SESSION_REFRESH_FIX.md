# 剧本库 401 与加载状态修复

日期：2026-10-29。

## 原因与改动

前端 `ensureSession` 只检查访问令牌是否存在，未使用后端已有的刷新接口；访问令牌失效后，请求直接返回 401。错误转换只读取 `detail`，而认证中间件返回 `message`，导致页面显示 Axios 英文错误。剧本库和手记页在加载失败后仍按空数组渲染空状态。

新增共享令牌存储模块和只读请求续期：GET/HEAD 收到401时，使用原账号续期凭据换发令牌，原请求最多重读一次。并发请求共享一次续期，浏览器 Web Locks 协调跨标签页的一次性凭据轮换；迟到的旧请求复用已换发令牌，避免再次消耗续期凭据。续期请求有10秒超时。

续期结果不能覆盖期间发生的新登录或登出。401、403、网络失败均不自动切换成访客；没有新续期令牌时删除其他身份残留的旧续期令牌。账号密码登录、匿名登录与刷新请求不携带旧访问令牌；`/api/auth/me` 仍携带凭据并支持同样的续期逻辑。

POST等写操作不自动重发，避免重复生成、付费或游戏指令。401与连接失败显示中文提示，业务错误码继续保留。

剧本库加载失败时只显示失败状态；续期也失败时，提供重新登录和明确选择访客浏览的入口。手记加载失败不再同时显示无记录提示。
